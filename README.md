# AI Developer Sentiment

Analysis of developer sentiment toward AI tools and technologies.

## Project Structure

```
AI-Developer-Sentiment/
├── data/
│   ├── raw/          # Original, unprocessed datasets
│   └── processed/    # Cleaned and transformed data
├── notebooks/        # Exploratory analysis and experiments
├── src/              # Reusable Python modules and scripts
├── dashboard/        # Interactive visualization app
├── report/           # Written findings and documentation
├── figures/          # Generated charts and visualizations
├── README.md
├── requirements.txt
└── .gitignore
```

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Usage

1. Place raw data in `data/raw/`.
2. Run preprocessing scripts from `src/`.
3. Explore results in `notebooks/` or the `dashboard/`.
